# worldofchips

Static site for https://worldofchips.com (served as plain files, no build step on the host).

## Country pages

Every country has a static, crawlable page at `/<slug>/` (e.g. `/japan/`, `/south-korea/`).
These are **generated** from the country data that lives in the inline `<script>` of `index.html`
(`countryData`, `brandUrls`, `countryContent`, and the shop picks `csm`).

After editing country data in `index.html`, regenerate and commit:

```sh
node scripts/build_country_pages.mjs            # lastmod = today
node scripts/build_country_pages.mjs --lastmod 2026-10-17
python3 scripts/validate_site.py                # HTML/JSON-LD/JS/link + news checks
```

The build writes `/<slug>/index.html`, `assets/site.css` (copied from index.html's `<style>`),
`sitemap.xml`, and the `BUILD:*` marker regions in `index.html`. Do not edit those by hand.
No npm install is needed (Node 16+, Python 3 stdlib).

## Chip news (weekly update)

The homepage `#news` grid (latest 6 stories), the `/news/` archive page and the `/news/` entry in
`sitemap.xml` are **generated** from `data/news.json`. Do not edit those by hand.

Each story in `data/news.json` (an array; order doesn't matter, the build sorts newest first):

| field | notes |
| --- | --- |
| `id` | unique lowercase-hyphen slug, e.g. `calbee-norishio-50th-anniversary-renewal` (also the card's `#anchor` on `/news/`) |
| `date` | `YYYY-MM-DD`, the date the source published/announced it |
| `title` | our own headline (≤ 110 chars) |
| `summary` | 40–80 words in **our own words** – never copy the source's text |
| `category` | one of `Industry`, `New Flavor`, `Safety Recall`, `Innovation`, `Sustainability`, `Investment`, `Regional` |
| `country` | optional country-page slug (e.g. `japan`, `united-kingdom`) – adds a link to that guide |
| `source_name` / `source_url` | the credible page you verified the story on (company release, regulator, trade/news outlet) |

Weekly workflow:

```sh
# 1. add new stories to data/news.json (keep old ones; they stay in the /news/ archive)
node scripts/build_news.mjs          # regenerates index.html #news, news/index.html, sitemap /news/ lastmod
python3 scripts/validate_site.py     # field checks + "generated files in sync" check
git add -A && git commit -m "News: week of YYYY-MM-DD"
```

The build is deterministic (no timestamps), so re-running it without data changes produces no diff;
`node scripts/build_news.mjs --check` exits non-zero if the generated files are stale.
`scripts/build_country_pages.mjs` keeps the `/news/` sitemap entry too, so the two builds can run in any order.

## Snack box comparison (`/snack-boxes/`)

`/snack-boxes/index.html` and its `sitemap.xml` entry are **generated** by `scripts/build_snack_boxes.mjs`.
All prices/facts live in the `BOXES` / `FAQS` data at the top of that script, each with the official
source URLs it was verified on. When re-checking (monthly-ish), update the data and `LAST_CHECKED`, then:

```sh
node scripts/build_snack_boxes.mjs   # regenerates snack-boxes/index.html + sitemap entry
python3 scripts/validate_site.py     # includes a "snack-box page in sync" check
```

Never guess a figure: if a company doesn't publish it, write "see site".
Brand links are plain official URLs with `rel="nofollow noopener"` and a `data-affiliate="<brand>"`
attribute (`bokksu`, `tokyotreat`, `sakuraco`, `japancrate`, `daebak`, `japancandystore`, `universalyums`, `mexicrate`, `snackcrate`).
When an affiliate program is approved, swap the `href` in the script (and add `sponsored` to `rel`).
`build_country_pages.mjs` and `build_news.mjs` both preserve the `/snack-boxes/` sitemap entry.

## Buyer's guides (`/best-japanese-chips/`, `/where-to-buy-asian-chips-europe/`, `/best-international-chip-variety-packs/`)

Generated by `scripts/build_guides.mjs` from the `GUIDES` data at the top of the script (facts, prices
and sources, all checked on `LAST_CHECKED`). Amazon product links are tagged searches unless the ASIN
page was opened and showed the item in stock (listed in `VERIFIED_ASINS`). The other builds preserve
the guides' sitemap entries; `validate_site.py` runs `build_guides.mjs --check`.

```sh
node scripts/build_guides.mjs
python3 scripts/validate_site.py
```

## AI search (llms.txt, IndexNow)

- Country pages carry a generated **Quick Facts** table and an **FAQ** section + `FAQPage` JSON-LD
  (from `scripts/build_country_pages.mjs`; answers use only data already on the page).
- `node scripts/build_llms.mjs` regenerates `/llms.txt` and `/llms-full.txt` from the built pages.
  Run it after the other builders; `--check` (also run by `validate_site.py`) fails if stale.
- IndexNow key file: `/70db554b0a1ac11d64c90d0d452d821e.txt`. After a deploy, run
  `node scripts/indexnow_ping.mjs` (or `--dry-run` to preview) to submit every sitemap URL.

## Community flavour submissions (moderated)

Visitors submit flavours at `/submit-a-flavor/` (form built in `scripts/guides_more.mjs`). The form posts to
FormSubmit.co (`https://formsubmit.co/michaelvdlooij@mail.grokbot.com`, free, no backend), with a captcha,
a honeypot (`_honey`), a `_subject`, a `_next` redirect to `/submit-a-flavor/?sent=1` (thank-you message) and
`multipart/form-data` so the photo arrives as an email attachment (FormSubmit limit: 10 MB total).

**One-time activation:** the first real submission makes FormSubmit send an activation email to the
inbox above. Click the link in it, or no submissions will be delivered. Until then the form shows FormSubmit's
"confirm your email" page.

Moderation steps:
1. Read the submission email. Approve only if the consent box was ticked, the photo looks like the
   submitter's own, and the content is chip-related and not offensive or promotional.
2. Save the photo (resize to about 800 px wide, JPG) to `assets/community/<id>.jpg`.
3. Add an entry to `data/community_flavors.json` (a JSON array, starting as `[]`):

```json
[
  {
    "id": "2026-11-uk-1",
    "country": "united-kingdom",
    "city": "Leeds",
    "flavor": "Chip Shop Curry",
    "brand": "Seabrook",
    "description": "Tastes like curry sauce on chips. Found at a corner shop.",
    "credit": "@handle",
    "photo": "/assets/community/2026-11-uk-1.jpg",
    "approved": "2026-11-02"
  }
]
```

   `country` must be an existing country slug. `city`, `credit` and `photo` may be `""`. Never publish the
   submitter's email.
4. Rebuild and validate: `node scripts/build_country_pages.mjs && node scripts/build_llms.mjs && python3 scripts/validate_site.py`.
   Entries appear in "Community Finds" on the country page and the 6 newest appear under the homepage map.
5. Commit, then open a PR and merge it.
